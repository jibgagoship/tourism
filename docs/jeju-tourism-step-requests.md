# 제주 관광 안내 프로젝트 - 단계별 요청사항

> 이 파일은 각 단계를 진행할 때 그대로 복사해서 요청(프롬프트)으로 사용하는 실습용 문서입니다.
> 한 단계씩 순서대로 요청하고, 결과를 확인한 뒤 다음 단계로 넘어가세요.

---

## STEP 1. 프로젝트 뼈대 만들기

```
제주 관광 안내 사이트를 만들고 싶어.
HTML/CSS/JS(또는 React) 기본 프로젝트 구조를 만들어줘.
페이지는 홈 / 관광지 목록 / 관광지 상세 / 코스 목록 / 코스 상세, 총 5개로 구성할 거야.
아직 디자인이나 데이터는 넣지 말고, 폴더 구조와 빈 페이지 뼈대만 먼저 만들어줘.
```

**완료 확인:** 폴더 구조가 보이고, 페이지 이동(라우팅)이 되는지 확인

---

## STEP 2. 관광지 데이터(.md) 3~5개 만들기

```
제주도 관광지 3~5곳을 소개하는 마크다운 데이터 파일을 만들어줘.
각 관광지마다 이름, 위치, 개방시간, 입장료, 설명, 방문 팁을 포함해줘.
카테고리는 자연 / 문화 / 음식 / 액티비티 중에서 골라서 표시해줘.
```

**완료 확인:** `.md` 파일이 생성되고 내용이 잘 정리되어 있는지 확인

---

## STEP 3. 마크다운을 화면에 보여주기

```
STEP 2에서 만든 관광지 마크다운 파일들을 읽어서
관광지 목록 페이지에 카드 형태(이름 + 짧은 설명)로 보여줘.
카드를 클릭하면 해당 관광지의 상세 정보(설명 전체)가 보이는 상세 페이지로 이동하게 해줘.
```

**완료 확인:** 목록 → 클릭 → 상세 페이지 이동이 실제로 동작하는지 확인

---

## STEP 4. 카테고리 필터 추가

```
관광지 목록 페이지에 카테고리 필터(자연/문화/음식/액티비티)를 추가해줘.
필터 버튼을 클릭하면 해당 카테고리 관광지만 보이게 해줘.
```

**완료 확인:** 필터 클릭 시 목록이 실제로 걸러지는지 확인

---

## STEP 5. 검색 기능 추가

```
관광지 목록 페이지 상단에 검색창을 추가해줘.
관광지 이름이나 설명에 검색어가 포함되면 결과에 나오게 해줘.
```

**완료 확인:** 검색어 입력 시 실시간으로 결과가 줄어드는지 확인

---

## STEP 6. 추천 코스 데이터(.md) 만들기

```
1일 코스와 2일 코스를 각각 1~2개씩 마크다운으로 만들어줘.
코스마다 제목, 기간, 테마, Day별 방문 순서(위에서 만든 관광지 이름 활용)를 넣어줘.
```

**완료 확인:** `.md` 파일 구조가 정리되어 있는지 확인

---

## STEP 7. 코스 목록/상세 페이지 만들기

```
STEP 6에서 만든 코스 데이터를 코스 목록 페이지에 카드로 보여주고,
클릭하면 Day별 일정이 순서대로 나오는 코스 상세 페이지로 이동하게 해줘.
```

**완료 확인:** 코스 카드 클릭 → Day별 일정이 보이는지 확인

---

## STEP 8. 홈페이지 완성

```
홈페이지에 다음을 추가해줘:
1) 상단에 제목과 검색창
2) 인기 관광지 3~4개 카드
3) 추천 코스 2개 카드
각 카드는 클릭하면 해당 상세 페이지로 이동하게 해줘.
```

**완료 확인:** 홈페이지에서 모든 링크가 정상 작동하는지 확인

---

## STEP 9. 반응형 디자인 적용

```
지금까지 만든 페이지들을 모바일 화면(좁은 화면)에서도 잘 보이도록
반응형으로 수정해줘. 특히 카드 목록이 모바일에서는 1열로 보이게 해줘.
```

**완료 확인:** 브라우저 창을 좁혀서 레이아웃이 깨지지 않는지 확인

---

## STEP 10. 최종 점검 및 마무리

```
지금까지 만든 프로젝트 전체를 점검해줘.
1) 깨진 링크나 콘솔 에러가 없는지 확인
2) 코드 정리(불필요한 코드 제거)
3) README.md에 프로젝트 소개와 실행 방법 정리
```

**완료 확인:** 에러 없이 전체 페이지가 잘 동작하는지 최종 확인

---

## 사용 방법

1. STEP 1부터 순서대로 진행하세요 (건너뛰지 않기)
2. 각 요청 아래 "완료 확인" 항목을 실제로 확인한 뒤 다음 단계로 넘어가세요
3. 결과가 마음에 안 들면 같은 단계에서 "~부분만 수정해줘" 식으로 추가 요청하면 됩니다
4. 막히는 부분이 있으면 해당 STEP 번호를 알려주면 더 자세히 도와드릴 수 있어요
